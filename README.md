# Estrutura de Dados Lineares

## Lista encadeada
**Complexidade:** `O(1)` para inserção e remoção no início; `O(n)` para busca e remoção por valor.

## Lista circular
**Complexidade:** `O(1)` para inserção no início e no fim e remoção no início; `O(n)` para busca.

## Fila
**Complexidade:** `O(1)` para inserção no fim (*enqueue*) e remoção no início (*dequeue*).

## Pilha
**Complexidade:** `O(1)` para inserção (*push*) e remoção (*pop*) no topo.

## Deque
**Complexidade:** `O(1)` para inserção e remoção em ambas as extremidades.
